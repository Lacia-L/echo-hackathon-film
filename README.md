# Echo·语镜

> 先听见回声，再决定下一个音。

AIGC 教育赛道 · Hackathon 参赛原型

## 这是什么

一句别人对你说的话、一段录音、一张老照片，背后往往藏着说话人没说出口的记忆与恐惧。
Echo·语镜把这句"回声"还原成它的来处，帮你分清：**哪部分是他的课题，哪部分才轮到你自己选。**

它同时服务两边：
- **被教育者**：听懂"为你好"背后，是怎样的不安与经历。
- **教育者**：照见自己——有没有把当年没走完的路，说成了对方必须走的前途。

## 对命题的回答

> 教育如何对待下一个像你一样的人？

教育的本质不是替人规划，而是帮他发掘真正的自我、在现实里追求自己想要的、遇见更好的自己。
我们很容易把"我经历过的"当成"他需要的"，借他的人生重打一场自己当年没赢的仗。
语镜做的，是把这份好意拆开，把"确认键"还给那个人。

## 功能

- 输入一句话 / 录一段音 / 选一张老照片
- 四步拆解：他说出口的 → 语镜还原的记忆 → 这是谁的课题 → 你的回应
- 「别人对我说 / 我对别人说」双视角：同一句话，两面镜子
- 与语镜聊聊：高认知对话，练习课题分离
- 我的回声记录

## 运行

纯静态单文件，无需构建。

- 本地：双击 `index.html`
- 线上：把本文件放仓库根目录，开启 GitHub Pages（main / root）即可访问。

## 技术

单文件 HTML + CSS + 原生 JS，无外部依赖；气泡 / 螺旋粒子为代码绘制。
（产品概念原型：线上可接 Whisper 语音 + LLM 情绪与动机推演 + AIGC 图像还原。）
